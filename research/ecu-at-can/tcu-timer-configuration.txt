Factory-document interpretation (conditional on compatible MCU)
---------------------------------------------------------------
Source: sources/renesas-sh7055s-hardware-rej09b0045-0200h.pdf, SHA256
359963cd6e34a2544a30b992d171681fb5cd953b51cd7610f3d6fd30b7f6497c.
Selected original text is saved in tcu-timer-configuration-manual-excerpts.txt.
PDF zero240/266, printed201/227, identifies PSCR1..4 and value1 as Pphi/2.
PSCR1 supplies channel2 and PSCR2 supplies channel6. PDF zero268/269 and
271/272 defines TCR2A/B and TCR6A/B zero as direct internal prescaled clock.
Thus the executed setup selects Pphi/2 for relevant channel2/6 counters.
Absolute peripheral clock Pphi remains unknown; no Hz, milliseconds or real
interrupt cadence follows from this ratio alone.
PDF zero346/347, printed307/308, defines PMDR=0 as on-duty, non-complementary
PWM for6A..D. This is programmed mode, not measured electrical behavior.
PDF zero685/696/697 identifies PBIOR/PBCRH/PBCRL/PBIR and explains PBCRL=0055
selects PB0/TO6A,PB1/TO6B,PB2/TO6C,PB3/TO6D. Prior verified buffer mapping gives:
 application channel0 -> F510 BFR6A -> PB0/TO6A
 application channel1 -> F512 BFR6B -> PB1/TO6B
 application channel2 -> F516 BFR6D -> PB3/TO6D
 application channel3 -> F514 BFR6C -> PB2/TO6C.
This is MCU port mapping, not board connector or solenoid identity.
PBIR F736 bit n inverts the ATU output when1. Tested setup does NOT write it;
all arbitrary initial values remain unchanged. The manual reset context has
exceptions (including WDT power-on), so un-inverted polarity is not established.
Actual chip identity, reset history, pin voltages and plant response remain open.
