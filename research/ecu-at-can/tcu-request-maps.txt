Constructor and callback linkage
--------------------------------
Full4CBA8 takes r4=event, r5=code, r6=operation, r7=record. It writes code to
record+1 and operation to+8, zeros words+4/+6 through real5BBEC(0.5), calls
2FBA4(A2B8,5E3F8,event) for byte+12, snapshots byte808C to+13 and words80C2/
80C4 to+14/+16, allocates priority1 through4C6C2 and saves handle at+2.
It returns2 and preserves previously initialized flags at+18. Thirty-six
fixtures cover all12 ring indices with three different head positions.
The ring is12 entries atA2BC with12-byte stride, matching event at entry+6;
2FBA4 returns the matching physical index. These tests do not establish who
created those queue entries. Missing-event returnFF and failed allocation
handling in outer callers are not verified; do not use synthetic bad handles.

Eight maps7656C..766FB have50-byte records: two count bytes6,6, six X-axis

Ramp capture, duration and completion
--------------------------------------
Full4CEF2 copies current word+4 to saved word+6, zeros byte8115[record+12]
and returns5. Full4D142 reads this timer byte and calls4D4CC for duration.
The duration table is selected by code:
  other763FC,6=7640B,7=7641A,8/11=76429,9=76438,10=76465.
Code7 with flag20 uses76447. Operation18 overrides76456;17 overrides76447.
Index is unsigned byte record+13. Tests cover indices0..14 in each15-byte
stock table; the runtime producer/bounds of808C are still open. Durations
range0..85 decimal in the selected stock tables. These are timer counts,
not milliseconds. Several indices producezero, which skips division.

For timer<duration, raw=u16(saved+6)*(duration-timer)//duration, with unsigned
word multiply and actual10CE4 division. Otherwise raw=0. The routine takes
signed16(raw), clamps belowzero, then applies the same92D5/9410 gates and
publishes through4C6DA. It does not increment the timer itself.4CF08 returns
1 iff timer>=duration, including immediate completion for durationzero.
Tested negative/sentinel boundary saved values are synthetic robustness
fixtures, not proof normal stock maps generate those values. Saved8000/FFFF
can initially clampzero and later become positive as the unsigned quotient
falls below8000. A positive7FFF result sets the record's active flag but is
withdrawn by the downstream list sentinel rule, producing slot2 modeFF.

Full4CF6A clears record+18 mask80, writes word+4=0 and sets the allocated
list entry tozero/mode0. This retains the allocation; it does not release it.
