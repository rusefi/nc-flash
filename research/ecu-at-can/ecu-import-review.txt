LFFEEE stock engine ECU import and transmission review
Date: 2026-10-05

RESULT
The imported LFFEEE image is an automatic-transmission engine ECU calibration.
The original LF9VEB image is calibrated for a six-speed manual. Both images
contain corresponding executable branches for different transmission modes.
Static analysis identifies a strong AT/MT configuration-selector candidate,
not merely tables with AT in their names. Full vehicle compatibility of an
altered LF9VEB image has not been established.

EXECUTABLE SELECTOR TRACE
LFFEEE reader 0x429E8 reads byte 0xB8296. LF9VEB reader 0x39380 reads 0xB858E.
When this byte is not FF, the reader returns it directly. When it is FF,
there is a separate RAM/configuration lookup and fallback path. Neither of
these supplied ROMs selects that FF path.

The return passes through an identity wrapper (AT 0x8C122, MT 0x83432).
Initialization at AT 0x42728 / MT 0x390C0 converts the value into mode flags:
    selector 0 -> 0x80
    selector 1 -> 0x40
    selector 3 -> 0xA0
    other      -> 0x00
Writes occur at AT 0x427D2 -> RAM 0xFFFF734A and
MT 0x3916A -> RAM 0xFFFF6C76.

AT code 0x3F600 and MT code 0x3DB58 both test bit 0x40 of that mode byte.
When set (the supplied MT calibration), the routine selects among the
calibrated gear ratios using the runtime gear and validity flags.
When clear (the supplied AT calibration), it instead multiplies two runtime
float inputs: AT RAM 0xFFFF6A3C and 0xFFFF6A38; MT equivalents 0xFFFF6A00
and 0xFFFF69FC. The origin/meaning of those inputs is not fully decoded here.
This mode branch exists in the original LF9VEB executable too.
Calling the selector AT/MT is an inference from its control flow and the two
known calibration types; no manufacturer symbol name has been recovered.

OTHER ENGINE ECU PATHS
The intake-pool compensation routine selects between two table descriptors
using a runtime timer: AT 0x451BA, timer RAM 0xFFFF7496; MT 0x4484E,
timer RAM 0xFFFF747E. Referenced table data:
    MT/timer-expired: AT 0xCC394, MT 0xCBF00 (same 8 float values).
    AT/timer-active:  AT 0xCC508, MT 0xCC03C (same 24 float values).
The DFCO code at AT 0x479CE / MT 0x47062 selects the two decay scalars above
using RAM 0xFFFF7EEE / 0xFFFF7DCA. These table names come from public
Romdrop metadata; the complete causal link from transmission mode to these
runtime timer flags has not been traced.

DIAGNOSTIC FLAGS ARE NOT SUFFICIENT EVIDENCE
C0101 TCM communication enable is 1 in both ROMs (AT 0xE1B0D; MT 0xE0975).
P0704 clutch-pedal and P0850 neutral-switch enables are also 1 in both.
Their presence does not distinguish AT from MT calibration.

LIMITS
These are different software/calibration families. The comparison establishes
shared engine-ECU branches and different stock configuration, not a verified
one-byte conversion or interchangeable flash images. Other calibration,
hardware, vehicle-network, and runtime behavior has not been fully matched.
No transmission-controller ROM was used in this review.
Public lffeee.xml includes Romdrop patch-specific definitions; it was used as
a reference, and those extra features were not assumed present in stock code.
