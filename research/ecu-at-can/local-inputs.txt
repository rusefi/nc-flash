Bounded peripheral model
------------------------
InputSamples maps only byte accesses F000..F006 and word accesses F72C/F764/
F746/F74E, all with FFFF prefix. Unknown addresses/widths and writes to RDR
or sampled input ports raise. RDR returns the explicitly supplied bank byte
selected by F72C bits14/15. SSR reads are fixtures:80 outside polling;
80 for a requested number of polls,then C0. All peripheral writes are logged.
These are sampled reads, not a full register model. In particular, writing
SSR status bits is not emulated as ordinary RAM or as a receive operation.
The bounded never-ready case stops at the interpreter's instruction limit
inside78CA..78D2, before RDR is read. It demonstrates the local polling loop
has no timeout; it does not model external watchdog/interrupt recovery.

Executed sampling and filtering
-------------------------------
76B4(bankbyte) saves/restores SR and uses real22E4/22F4 interrupt-mask helpers.
SCR0 is masked with0B, then FC; SMR0=80, SDCR0=F2, BRR0=4. Bank0 clears
F72C bits14/15;bank1 sets14/clears15;all other byte values clear14/set15.
Other port bits survive. SCR0 becomes(SCR0&0B)|30;786E receives argumentFF.

786E executes the794C NOP delay, clears F764 bit0 through E744, delays,
writes SSR=(SSR&87)|80, writes TDR=FF, then SSR=(SSR&7F)|78. It waits for
SSR bit40 at78CA..78D2, reads RDR, writes SSR=(SSR&BF)|B8, delays and sets
F764 bit0. The returned byte is preserved; SR interrupt-mask bits restore.
This is evidence of serial acquisition and bank/strobe control, not external
chip identification, pin multiplexing validation or an electrical waveform.

CA94 initialization copies current samples into filtered/previous pairs:
  F746 word ->44A0/44AA; F74E word ->44A2/44AC;
  76B4(1) byte ->44A4/44AE;76B4(2) byte ->44A5/44AF;
  CBC8 Boolean ->44A6/44A8 words.
CBC8 returns unsigned word401C>=8000. CA94 leaves44B0 untouched.
CADE updates the first four channels every call with
  filtered=((previous|current)&filtered)|(previous&current), previous=current.
This holds the old state when samples disagree and changes after two
consistent samples. Only when byte4004 differs from44B0 does it sample CBC8,
filter44A6/44A8 by the same rule and cache4004 into44B0.

The saved lifecycle starts bank1=FF. FF,FE,FF,FE leaves MT231 byte1=0;
a second FE changes it to04. BE once retains04;BE twice changes to06.
FF once retains06;FF twice clears0. Other payload bytes are FF,FF,FF,0,0,0,0
as described in mt-can231.txt. Diagnostic latches are zero in this lifecycle.

Manual corroboration (register naming only)
------------------------------------------
Renesas SH-2E SH7058 F-ZTAT Hardware Manual, REJ09B0046-0300H,
Rev3.0 Sep2004, sections15/19 and register tables, accessed2026-10-06:
https://www.renesas.com/en/document/mah/sh-2e-sh7058-f-ztat-tm-hardware-manual
PDF SHA2569c17aecfbe143d5c3f69efc536923e557c5c867fa2a50d917908643c5e58d137.
F000..F006 map SMR0,BRR0,SCR0,TDR0,SSR0,RDR0,SDCR0. SMR bit7 selects
synchronous operation; SSR bit6 indicates receive data available. F72C is
PHDR and F764 is PGDR. Register correspondence supports the interpretation;
it does not independently identify the board's external input device.
Manual source retained by provenance rather than copying the whole PDF.
