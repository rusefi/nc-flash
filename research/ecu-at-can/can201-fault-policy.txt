Verified aggregation
--------------------
570F6 builds 51 mapped summary bytes A958..A98A. It does not itself write
A98E. Separate routine 57258 builds ten aggregates A98B..A994 using ten
four-byte, zero-terminated index lists at 5FCBC. A98E's list at 5FCC8 is
1F 20 24 00, selecting A977, A978, A97C. Their diagnostic groups are 35,
36, 3A, respectively. The records at 5EB78+16*group contain report codes
C073, C100 and 0000; group3A has no established standard DTC identity.

57258 ORs contributor bits 1,2,4 (masks 02,04,10). If either mask02 or04
is present, it sets aggregate mask08 and clears mask01; otherwise mask01
is set. Stored history mask10 alone does not assert mask08. Both provisional
and confirmed active states can assert it.

57258 -> A98E mask08 -> 21C1C -> 92C9 mask40 has two verified effects:
  2055C substitutes ROM76DDE=20480 for the normal CAN201-derived80E8;
  2513E inhibits24FA0, clearing9454 and CAN216 byte7 mask20.
50C9A publishes A4E4=4 during substitution. In the admitted engine fixture,
the cleared request releases the four cylinder commands from zero to one.
These are software command values; physical actuation is not established.

146 group-mapping cases cover each of73 groups with raw active02 or04.
Only35,36,3A assert this aggregate.512 combinations of the three mapped
summary bytes execute aggregation, conversion, TCU request generation,
CAN216 packing and the existing ECU command chain. History-only values
retain normal conversion/request operation. CAN201 raw16000 gives8814=4000,
normal80E8=10240 and fixture cut request1; substitution gives20480 and
request0 because the diagnostic inhibit takes precedence over hysteresis.

Verified communication loss and recovery
----------------------------------------
Fourteen persistent-TCU-state lifecycles cover loss of each enabled class0
record (IDs200,201,215,240,420,4EC,4F1) with80A4=0 and1. Original helpers
19D44/19E10/19DC0 set/check/recover record deadlines;1A598 producesgroup36;

the policy.2055C/24FA0 and the paired CAN216/ECU chain verify its effects.
Static56F80 task ordering corroborates group processing ->57F50 ->570F6
->57258, but the complete task/scheduler is not emulated.

Qualification durations from each receive record+22:
  200,201,215,4EC:500 ticks;240,420:2000 ticks;4F1:5000 ticks.
Loss of any of these frames can substitute CAN201 and inhibit the request,
including when CAN201 itself continues to arrive. Initial receipt expiry is
distinct from the qualified diagnostic transition. Restored receipt alone
does not immediately clear active policy. With80A4=0 it clears strictly after
5000 healthy ticks;80A4=1 retains active policy in these fixtures.

Example missing201, timer initialized at100,80A4=0:
  tick100: normal;110: expiry bit set, still normal;599: still normal;
  600: qualified active04, A98E=1C, substitution20480, cut request0;
  601: receipt restored, policy remains active;
  5601: exactly5000 healthy ticks, still active;
  5602: active clears, A98E=11, normal10240 and request1 return.
Serialized C1 00 FF remains stored after active policy clears. This stored
history is independently distinguishable from the active control inhibit.
