Executed firmware
-----------------
4DFE tests software byte404B. Nonzero calls5E38 then clears404B, even when
5E38 skips capture. Zero calls5CF4 only when4049 is exactly1; otherwise no-op.
404B is an armed-operation marker, NOT the hardware ADC completion flag.
531E sets404B=1 after configuring the alternate acquisition. Periodic4CE2
clears it before starting bank1. Literal references are candidate leads, not
an exhaustive proof that no other indirect writer exists.

F29C reads FFFFF838, writes its oldbyte&7F, then tailcalls4DFE. All256 old
bytes are tested, including synthetic states that would not raise an interrupt.
The callback itself does not gate entry on ADF/ADIE. Live interrupt delivery
is distinct from executing this entry in a harness.

5E38: if40A1!=0, no changes. Otherwise copies retained4096->4078 and409A->407A,
then reads F836->4098 and F816->409C and sets409E=1. It does not set40A1 or
clear409E when skipped. Reads are channels23 and11; no new source identity for
traction's channel1/8 or CAN211/21A is established by this path.

5CF4 increments byte40A2 with wrap; if newvalue>=2 resets it to0. Newvalue1
returns immediately; zero performs work (old255 wraps0 and also performs it).
It reads F836->4096 and F816->409A. Float4068<=1000 sets40A0=1; >1050 sets0;
(1000,1050] retains oldbyte, including nonboolean values. These stock thresholds
are ROM DC3EC=1000.0 andDC3F0=50.0. No physical units assigned.
It calls531E(0), then5D62(40A0), then clears40A1. NaNs are outside tested inputs.

531E argument zero selects ADCSR0/1=0B/4B, nonzero=0A/4A. For each bank it
clears ADCR bit20, reads priorADCSR, writes selectedADCSR, ORs trigger-register
bit80, then writes ADCR=(old afterclear&AF)|80. ADTRGR0=F76E, ADTRGR1=F72E.
Nested22E4/22F4 save/restore masks execute, including all16 mask values with
an explicit synthetic descriptor for the SR-zero path; no scheduler dispatch.

5D62 uses lowbyte argument (unlike531E's full-register zero test):
Let B=word(F440)+4. All writes below truncate to16bits. For argumentlowbyte0:
 F64C=44 twice; F450=B+25; F64E=25 twice; F452=B;
 F64A=1 twice; F44E=B+20.
For nonzero lowbyte: F64C=25 twice; F450=B; F64E=14 twice; F452=B+25;
F64A/F44E unchanged formula. Clears40A3. Duplicate writes execute original
11070; stock ROM DC3D6/D8/DA/DC=[25,44,14,20]. No counter ticking is simulated.

Verification and limits
-----------------------
verify_control_acquisition_completion.py adds a local bounded subclass with
two byte and seven word peripheral latches, plus inherited explicit ADC inputs.
All applicationRAM, ADC read order, existingADC register I/O and additional
register I/O compared with independent formulas. Unsupported widths/addresses
fail. These latches do not implement reserved bits/read-clear side effects,
conversion, interrupts, timer counting, pin levels or feedback. Arbitrary
register values test software bit behavior, not legal hardware states.
Original helpers execute; no ROM, shared interpreter/verifier or production edit.

Initial test failed because shared run(e,address) called e.run with default
argumentzero, overriding preloadedR4. Fixed local adapter to pass its explicit
argument to e.run. This was a harness argument error, not a firmware/model change.
First complete run passed; final extension tests all256 acknowledgementbytes
and injects retained callbacks only when software ADIE1 is enabled. Final
results:256 capture cases,96 arming calls,42 timer cases,5120 alternate
updates,192 followup+callback pairs,256 acknowledgement bytes,320 retained
schedule calls,7 injected callbacks and4 expected access rejections pass.
Results recorded in control-acquisition-completion-verification.json.

Retained320 periodic E276..E282 manager/scaler calls start with zero counters.
Software enables ADIE1 at calls64/128/192/256/320. Explicit successful-conversion
callbacks are injected at those points. 5CF4 halfcounter arms at128 and256;
only then a second explicit conversion/callback is injected with changed11/23
samples. Result pairs at128=[53824,30016,14592,20992]; at256=
[62016,38208,22784,29184], ordered4078/407A/4098/409C. This distinguishes the
saved initial pair from the subsequent pair. Seven total injected callbacks.
Physical conversion success/delivery is an explicit assumption, not a result;
128 calls is not milliseconds and does not establish globaltask cadence.
No integrated engine/TCU/DSC plant or CAN timing closure claimed.
