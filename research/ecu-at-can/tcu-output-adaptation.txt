18C38 adaptation (zero-based channel i, word offset j=2*i)
Let B=u16(A5D4+j), E=s16(8A34+j). Normalized error N=s16(trunc(E*1000/B))
when B nonzero, otherwise0. Admission requires B>=200,8AB6<E<8AB4 and
8ABA<N<8AB8, all strict signed-word bounds. Rejection retains all state.
Stock initial bounds are E in(-100,100), N in(-50,50).

On admission:
 T=signed-word clamp(trunc(trunc(s16(8AAC+j)*80/100)*1000/B),3700,9700).
 G=s16(8A6C+j); limited step D=signed-word clamp((s16(T)-G)>>4,-100,100).
 The shifts are arithmetic floor shifts, not truncation toward zero.
 Difference8AC2+j receives abs(s16(T-G)); it is then read as signedword.
 If8A60+i is zero and that signed difference<ROM5C5E8=500, set8A60+i=1.
 This is sticky here. It feeds the reset branch of the earlier18A44 handoff.
 A stored magnitude32768 is negative on this signed comparison; arbitrary
 inputs test the behavior without assigning it a physical meaning.

If byte89AC is nonzero, update gain and compensate the retained accumulator:
 - On first update (8ABD+i==0), use full T-G instead of the limited step.
   When unsigned89AA lies inclusively within ROM5FCFC..5FCFE=10..1000,
   replace T by4788+trunc(s16(89A8)*223/10) first. Set8ABD+i=1.
 - For later nonzero8ABD, use limited D. Nonboolean flags count as nonzero.
 - Integral8A9C+4*i := old - s16(D)*B, with32-bit wrap.
 - Gain8A6C+j := G+D, with16-bit wrap.
Even when89AC is zero, an admitted call still updates the difference/sticky
qualification and rescales8A8C and8A7C from base gains8A94/8A84 multiplied
by unsigned current8A6C divided by unsigned8A74. Products wrap32 bits and
the original5AE90 division treats the product as signed. Bounds/helpers
retain their actual low-word comparison semantics; no idealized real math.

18E76 offset
UnsignedA518 clamps to8000..16000, subtracts8000, then10700 interpolates a
channel-specific five-point table at pointer8AD4+12*i using spacing2000.
Stock initialized pointer5F84C has a sixth FFFF sentinel per row. The result
is unsigned-word clamped0..32767 into8A44+j. Original10700/5AC9C execute.
AtA518=12000 offsets are[1750,1750,1750,1680]. These values subsequently
affect14280 buffer writes; no voltage units or physical calibration claim.

18830 dispatcher
The original comparison is unsigned32(s16(8ACA)) > unsigned32(s16(8ACC));
this matters for raw words>=32768. On true, reset8ACA=0 and dispatch one
function from ROM5C5EC: phases0..3 call18C38,4..7 call18E76. The latter sees
arguments256..259 whose low bytes select channels0..3. Increment phase and
wrap after7. Invalid phase bytes are not claimed tested or safe.
After dispatch, if unsigned8AD0>3000, set8ACC=15 and signed8AB4/8AB6=5/-5.
Increment8AD0 and8ACA with16-bit wrap. Threshold comparison uses the old age;
the changed limits remain after age wraps, because this body has no restore.
From stock init age0/count1/limit3, first dispatch is call4, then8..3000;
limit changes on call3002 and next dispatches are3016,3032. Calls are not ms.
All eight phases are verified through original indirect function calls.

Retained handoff
The integrated160-call replay takes one sample of all four ADC channels per
rotating channel service; after startup this gives four accumulated samples
per service. Then it executes one dispatcher call. This is explicit harness
scheduling, not proof of complete127BA/127FC cadence. Constant ADCcount368
produces measured499 after four samples; request500 gives error1.19 admitted

An earlier passing draft used four acquisitions per rotating service, leaving

It was replaced by the explicit four-per-channel schedule above and a required
admitted-count assertion. No failing firmware claim arose from that draft.

168AC timer initialization and factory register interpretation
All256 initial F401 byte values tested. Exact accesses:
 read F401; write F401&FB; write F400=0; clear RAM87F4 via original16926;
 zero F506/F504/F502/F500; write33333 to words in this order:
 F50A,F508,F50E,F50C,F512,F510,F516,F514,F51A,F518,F51E,F51C;
 write F400=0 again; F600=0; F604=4166; F400=0F;
 reread F401 and set bit04. Other F401 bits are preserved.
The software initializer writes are executed; interrupt bodies1692E/169A4
in the same disassembly are STATIC leads only, including1227E/11F7C callbacks.

Renesas SH7055S-compatible manual table11.3 identifies F401/F400 as TSTR1/2,
F500..506 as TCNT6A..D, F508..50E as CYLR6A..D, F510..516 as BFR6A..D,
F518..51E as DTR6A..D, andF600/F604 as TCNT2A/GR2A. Section11.2.1 identifies
TSTR1 bit2 as2A start and TSTR2 low four bits as6A..D starts. This supports
the interpretation of initialized cycles/duty/buffers and enabled channels;
it does not establish input clock, PWM mode, pin function, interrupt delivery
or electrical output. TSTR2=0F also leaves channel7 start bits clear.
