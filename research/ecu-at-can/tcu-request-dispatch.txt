State machine, verified under stock descriptors
------------------------------------------------
Manager group5/operation2 visits active ring entries and queues group8/
operation4 updates. Generic2FEF8 checks the global guard first, then the
current state's predicate/action, then the selected state's update handler.
It stores a returned new state after the handler call. Only one state-specific
transition is selected per call; it does not immediately re-test the next
state's predicate. A transition can run its new numeric handler that same call.

  state2: no active reduction; handler4CF6A writeszero/mode0.
          Predicate4CD18 true ->4CDF2 ->state3.
  state3: handler4D010 publishes stock map reduction.
          Predicate4CE5E true ->4CE7A ->state4 orstate5.
  state4: handler4D010 keeps calculating the map request.
          Predicate4CEC6 true ->4CEF2 capture/reset ->state5.
  state5: handler4D142 calculates decay from captured request.
          Predicate4CF08 true ->4CF3A release ->state1/cleanup.

4CDF2 snapshots95AE bit0 into record+18 bit20 through4D7EC, then returns3.
Its manager-state3 operation-change notification branch remains untested;
these full lifecycles use manager-state2. Constructor snapshots80C2/80C4
and808C; current80F6 remains a live map input as proved in the preceding work.

Five-way index and three parameter columns
-------------------------------------------
Full3138A reads byte800B and takes its code argument through316A8 to select
one of seven5-byte threshold rows70A20. Codes0..4/5..9 selectrows0..4,
code10 selects5 and other bytecodes select6. Output808C is the number of

This resolves the earlier broad15-index table tests: each15-byte group at

(advance margin);4D3D8 selects group+10+index (hold duration). Family selection
