317E4(index), descending initial timer:
  delay = ROM byte70A8A[5*family + u8(808C)]
  if record operation !=0: delay=0
  admitted = s16(8380 +2*index) >=2*delay
The operation override executes the original +0.5 conversion helper5BBEC;
its integer result truncates to0. It is not an invented bypass in the harness.
All valid808C banks0..4 are tested; production of this range is independently
verified in tcu-request-dispatch.txt. Stock delays are6 for families0..2 and3
for families3..6, invariant across these five banks. Signed negative timer
values are not admitted, including FFFF; do not interpret them as large ages.

3241C(index,code), departure predicate:
  either92C6 bit1 or bit4 -> no transition (-1)
  from = ROM5D428[code]
  measured = s16(80EE)
  reference = s32(9218 +4*from)
  threshold = s16(70AEE +2*(family+5)) =128 in this stock image
  admitted timer AND measured >= reference+threshold ->1; otherwise -1
Other tested92C6 bits2/5/7 do not inhibit this local predicate. They can
affect other paths, including cancellation; this is not a global permission.

324CE(index,code,operation), target qualification:
92C6 bits1/4 return -1 without touching bounds/counter/971A. Otherwise it
uses to=ROM5D446[code], creates lower=reference-128 and upper=reference+128
in9704/9700 via original software arithmetic, then dispatches by direction.
For descending direction, it clears971A bit1 and calls327B0.

327B0 qualifying measurement:
  codes5/6/7: lower <= measured < upper
  codes8/9/10: that band OR measured < s16(770BC), stock128
  code11: measured >= lower (no upper bound)
If qualified, byte96EF[index] increments with saturation255; otherwise zero.
Count threshold is ROM70B14[2*family + bool(9410 bit1)]:
  code     bit1 clear   bit1 set
   5           20         20
   6           20         50
   7           20         50
   8            5         30
   9           20         32
  10           12         20
  11           12         50

do not substitute the function's operation argument or the record field.
