mapA25CC ->A740; mapA25E0 ->A738. Both have18 X and30 Y entries.
X spans750..7500, Y spans0..200. Forward X interpolation clamps to endpoint
rows. Each tested interpolated Z row is nondecreasing (asserted by oracle).
Select the enclosing Z interval, using first/last interval outside its range;
invert with Y bounds lo/hi and forward values a/b:
 R(R(R(R(b-target)*lo)+R(R(target-a)*hi)) /
   max(floatBits3727C5AC, min(10000,R(b-a))))
The inversion EXTRAPOLATES outside map output range, before later limiting.
It can produce very large intermediate values across an almost-flat endpoint
interval. This is executed firmware behavior, not a physical-command claim.
The independent oracle uses bisect on forward map samples rather than the
firmware's embedded jump-table search. Samples include X below/above endpoints,
interior X, negative and large targets, zero and positive offsets.
